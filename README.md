# Sales Data Analysis

## Overview
This project performs exploratory data analysis on a small sales dataset to understand monthly sales trends and profit patterns using Python.

## Tools Used
- Python (pandas, matplotlib)

## Features
- Load and analyze sales data from CSV
- Calculate total sales and average profit
- Visualize monthly sales trend using line chart

## How to Run
1. Keep `sales_data.csv` and `sales_analysis.py` in the same folder.
2. Install libraries: pandas, matplotlib.
3. Run: python sales_analysis.py
4. View `monthly_sales_trend.png` for output chart.
